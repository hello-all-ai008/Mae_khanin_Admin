# สรุปสถานะการเชื่อมต่อฐานข้อมูล (Database Connection Status)
อ้างอิงโครงสร้างจาก `DatabaseFlow.jsx`

## 1. หน้า EventManager.jsx (และ Setup Components ย่อย)
หน้านี้เป็นศูนย์กลางในการตั้งค่างานวิ่งทั้งหมด (Event Setup)

**✅ จุดที่เชื่อมต่อกับ Database แล้ว:**
- **ตาราง `EVENTS`:** เชื่อมต่อเรียบร้อยแล้ว มีการดึงข้อมูล (Select), สร้างงานใหม่ (Insert), แก้ไข (Update) และลบ (Delete) ผ่าน `supabase.from('events')`
- **ตารางที่เกี่ยวข้องกับการตั้งค่างาน (Sub-setup):** 
  - การจัดการรุ่นระยะทาง (`CATEGORIES`), สถานที่ (`LOCATIONS`), จุดสแกน (`STATIONS`), จุดตรวจสอบ (`CHECKPOINT`) และเจ้าหน้าที่ (`STAFF`) มีการเรียกใช้งานผ่าน Supabase API เบื้องต้นแล้วในไฟล์ Setup ย่อย

**⚠️ จุดที่ต้องระวัง / ยังไม่สมบูรณ์:**
- ตาราง `STAFF`: ใน `StaffSetup.jsx` มีการดัก Error ไว้ว่าถ้า Insert ลงฐานข้อมูลไม่ได้ จะเปลี่ยนไปบันทึกลง `localStorage` แทน (Fallback) ดังนั้น**ต้องมั่นใจว่าได้รัน SQL สร้างตาราง `staff` ใน Supabase แล้ว** (ดูโค้ด SQL ได้ในหน้า Database Flow)
- ตาราง `ACTION_LOGS`: ปัจจุบันยังไม่มีการบันทึกประวัติการทำรายการ (Action Logs) เมื่อมีการลบงานวิ่งหรือแก้ไขข้อมูลสำคัญ

---

## 2. หน้า StaffManager.jsx
หน้าที่ใช้จัดการรายชื่อเจ้าหน้าที่/คนสแกน (เรียกใช้ `StaffSetup.jsx` ด้านในอีกที)

**✅ จุดที่เชื่อมต่อกับ Database แล้ว:**
- **ตาราง `EVENTS`:** เชื่อมต่อเพื่อดึงรายชื่องานวิ่งมาแสดงใน Dropdown สำหรับกรองข้อมูลเจ้าหน้าที่ตามงาน (`supabase.from('events').select('id, name')`)
- **ตาราง `STAFF` & `STATIONS`:** ดึงข้อมูลเจ้าหน้าที่และจุดสแกนมาแสดงเพื่อผูกเจ้าหน้าที่เข้ากับจุดสแกน

**⚠️ จุดที่ต้องระวัง / ยังไม่สมบูรณ์:**
- เช่นเดียวกับ EventManager ต้องรัน SQL สร้างตาราง `STAFF` เพื่อให้ใช้งานเชื่อมกับ Database ได้ 100% โดยไม่พึ่งพา LocalStorage

## 3. ฟังก์ชัน `importRunners` (ใน RaceContext.jsx)
ฟังก์ชันที่รับผิดชอบการนำเข้าข้อมูลนักวิ่งจากไฟล์ Excel/CSV

**❌ จุดที่ยังไม่ได้เชื่อมต่อ (ต้องทำเพิ่ม):**
- **ปัจจุบัน:** โค้ดยังทำงานแค่ใน Local State ของ React เท่านั้น (`setRunners(prev => [...prev, ...newRunners])`) ยังไม่มีการส่งข้อมูลขึ้น Supabase
- **ตารางที่ต้องเชื่อมต่อ:** 
  1. **ตาราง `RUNNERS` (หลัก):** ต้องเปลี่ยน/เพิ่มโค้ดให้ทำการ `supabase.from('runners').insert(newRunners)` เพื่อบันทึกรายชื่อเข้า Database
  2. **ความสัมพันธ์ (Foreign Keys):** ก่อน Insert ข้อมูลลง `RUNNERS` ต้องตรวจสอบให้แน่ใจว่าได้ระบุ `event_id` และ `category_id` ถูกต้องตามตาราง `EVENTS` และ `CATEGORIES` 
  3. **ตาราง `USERS` (ทางเลือก):** หากระบบบังคับให้ทุกคนต้องมี Account อาจจะต้องเช็คและ Insert ลงตาราง `USERS` ก่อน แต่ตาม ERD กำหนดให้ `user_id` ใน `RUNNERS` เป็น nullable ได้ ดังนั้นสำหรับการ Import ไฟล์ Excel สามารถ Insert ข้อมูลลง `RUNNERS` ได้เลยโดยไม่ต้องผูก User
