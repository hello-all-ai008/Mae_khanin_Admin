1 ปรับปรุงตารางผลการแข่งขัน (Live Leaderboard) และการแสดงผลภาษาอังกฤษ

เดิมทีทั้งใน Rohn-Admin (LiveLeaderboard.jsx) และ Rohn-Runner (Leaderboard.jsx) เมื่อเปิดดูบนโทรศัพท์มือถือ ตารางแต่ละรุ่นจะกินพื้นที่แนวตั้งเต็มความกว้าง (1 คอลัมน์) ขนาดตัวหนังสือและ Padding ใหญ่ ทำให้ต้องเลื่อนจอนานมากเพื่อดูผลรุ่นต่างๆ นอกจากนี้ ชื่อรุ่นและเพศที่ดึงมาจากฐานข้อมูลจะมีข้อความภาษาไทยปนภาษาอังกฤษ เช่น 40-49 ปี (40-49 years) หรือ ชาย (Male)

🔤 แสดงเฉพาะภาษาอังกฤษในวงเล็บ

สร้างและขยายความสามารถฟังก์ชัน formatEnglishLabel(val) ให้รองรับทุกกรณี:

  • ดึงเฉพาะข้อความภาษาอังกฤษในวงเล็บ (...) มาแสดง เช่น 40-49 ปี (40-49 years) ➔ 40-49 years
  • แปลงเพศเป็นภาษาอังกฤษสากล ชาย (Male) ➔ Male, หญิง (Female) ➔ Female
  • ป้ายทำเนียบ Overall เปลี่ยนจาก ชาย/หญิง เป็น Male/Female และตัดคำนำหน้าภาษาไทย "รุ่น" ออก
  • หัวข้อตารางแสดงเป็นภาษาอังกฤษล้วน เช่น 10KM | 40-49 years (Male)
  • มีระบบ Fallback อัจฉริยะรองรับกรณีข้อมูลใน DB มีแค่ภาษาไทยล้วน

📱 UI โทรศัพท์แบบหลายตาราง (Multi-Table Grid)

จัดวางเลย์เอาต์ใหม่ให้เห็นหลายตารางพร้อมกันโดยไม่ต้องเลื่อนหน้าจอเยอะ:

  • มือถือ (≤ 768px): ปรับ Grid เป็น 2 คอลัมน์คู่ขนาน (repeat(2, minmax(0, 1fr)))
  • ลด Padding ตารางเหลือเพียง 6px-8px และลดความสูงแถวนักวิ่ง
  • ย่อขนาดตัวอักษรลงเป็น 0.68rem - 0.72rem พร้อม Truncate ป้องกันชื่อยาวล้น
  • ความสูงของแต่ละตารางเหลือเพียง ~135px - 145px ทำให้หน้าจอมือถือมาตรฐานสามารถมองเห็นได้ทีละ 4-6 ตารางพร้อมกัน
  • Desktop/Tablet: แสดงผล 4-5 ตารางต่อแถวอย่างสวยงามและสมดุล

2 หน้าใหม่ใน Rohn-Admin: จัดการสถานะนักวิ่ง / รีเซ็ตเวลา (RunnerProgressControl)

เพิ่มหน้าใหม่ภายใต้เมนู "จัดการข้อมูล" ในโปรเจกต์ Rohn-Admin (ที่ Route /runner-progress-control) เพื่อให้อาจารย์และผู้จัดสามารถควบคุม ตรวจสอบ และทดสอบระบบก่อนการแข่งขันจริง:

ความสามารถหลัก รายละเอียดการทำงาน
ตรวจสอบเส้นทางและจุดสแกน แสดงผัง Checkpoint ของนักวิ่งแต่ละคนตามระยะทาง/รุ่นที่ลงทะเบียน (อ้างอิง Flow จาก DatabaseFlow.jsx) ตรวจสอบได้ว่าใครต้องผ่านสถานีไหนบ้าง
จัดการสถานะ DNS และ DNF มีปุ่มคลิกกำหนดสถานะ DNS (ไม่มาแข่งขัน) หรือ DNF (วิ่งไม่จบการแข่งขัน) ได้แบบรายบุคคลอย่างรวดเร็ว
แก้ไขและรีเซ็ตเวลา (Timing Override) มีหน้าต่าง Modal ตรวจสอบ/แก้ไขเวลา Check-in, Start Gun, CP แต่ละจุด และ Finish Time รายบุคคล
ระบบรีเซ็ตเพื่อการทดสอบ (Test Reset) มีปุ่ม Bulk Reset สถานะและเวลาการสแกนทั้งหมดของงานเพื่อเริ่มทดสอบรอบใหม่ (Dry-Run Test) พร้อมระบบยืนยันความปลอดภัยเพื่อป้องกันการกดพลาด

3 หน้าใหม่ใน Rohn-Admin & Rohn-Runner: จัดการการแสดงผลหน้า Runner (RunnerPageConfig)

เพิ่มระบบควบคุมการเปิด/ปิดเมนูในหน้าแรกของฝั่งนักวิ่ง (Rohn-Runner/src/pages/Home.jsx) ผ่านหน้า Admin (/runner-page-config):

ฝั่ง Rohn-Admin

  • หน้าจัดการแสดงผลเมนูนักวิ่ง มี Checkbox ให้ Admin ติ๊กเลือกเปิด/ปิดการเข้าถึงแต่ละเมนู
  • ควบคุมได้ทุกหน้า: ค้นหา BIB, สแกนจุดเช็คพอยท์, Live Leaderboard, E-Slip, จอถ่ายทอดสด Monitor
  • บันทึกการตั้งค่าลงฐานข้อมูลส่วนกลางทันที

ฝั่ง Rohn-Runner

  • RunnerContext.jsx ดึงค่า Config การเปิด/ปิดหน้าอัตโนมัติ
  • หน้า Home.jsx ปรับการแสดงผลการ์ดเมนูตามที่ Admin อนุญาต
  • หากเมนูใดถูกปิด จะซ่อนหรือแสดงสถานะแจ้งเตือนผู้ใช้งานอย่างเป็นมิตร

4 ปรับปรุงหน้าจอ Monitor (จอถ่ายทอดสด)

ใน Rohn-Runner/src/pages/Monitor.jsx ได้ปรับปรุงส่วนควบคุมการทำงานให้เหมาะสมกับการขึ้นจอทีวี/โปรเจกเตอร์:

  • เพิ่มปุ่มพับเก็บเมนูควบคุม ⚙️ ตั้งค่า (Settings) / X ซ่อน (Close) เพื่อไม่ให้บดบังข้อมูลนักวิ่ง แผนที่ความสูง และโลโก้งานขณะฉายขึ้นจอ
  • ปรับขนาดแถบลากแบ่งสัดส่วนหน้าจอ (Resizer Bar) ให้รองรับทั้งการสัมผัส (Touch) และการคลิกเมาส์
  • จัดระเบียบขนาดโลโก้ผู้สนับสนุนด้านล่างและแผนที่ 10KM/5KM ให้แสดงผลพอดีในทุกขนาดหน้าจอ
