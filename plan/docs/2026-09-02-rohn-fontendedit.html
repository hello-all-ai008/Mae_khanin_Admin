สรุปการอัปเดต Frontend (2026-09-02)

1. งานที่ดำเนินการเสร็จสิ้น (Work Accomplished)

  • ปรับโครงสร้างเมนู: จัดกลุ่มเมนู "สรุปผล" ให้อยู่ในรูปแบบ Dropdown และย้ายไปต่อจาก "เครื่องมือระบบ" ในหน้า Navbar.jsx
  • จัดเรียงคอลัมน์ตาราง: ย้ายคอลัมน์ "จัดการ" และปุ่ม "พิมพ์ e-Slip" มาไว้ด้านหน้าสุดในตาราง RunnersList.jsx และ OverallDashboard.jsx
  • ปรับปรุง e-Slip: แยกคอมโพเนนต์ ESlip.jsx ออกมาต่างหาก รองรับขนาดหน้าจอมือถือ และเพิ่ม Media Query @media print เพื่อให้พิมพ์ผ่านเบราว์เซอร์ได้สวยงาม
  • จัดการสีของระยะวิ่ง: เพิ่มคอลัมน์ color ลงในตาราง categories และเพิ่มช่องตั้งค่าสีใน CategoriesSetup.jsx โดยสีดังกล่าวจะไปแสดงที่แถบหัวตารางของ LiveLeaderboard.jsx อัตโนมัติ
  • Rebranding เป็น "ROHN": เปลี่ยนชื่อระบบจาก TrailTime เป็น ROHN, ปรับโทนสีหลักเป็นโทนน้ำเงินเข้ม-ม่วง (รหัสสีพื้นฐาน: Deep Navy #020b5e, Purple #8b2df6, Indigo #6366f1, Slate Navy #0f172a) ตามรูปภาพอ้างอิง และเปลี่ยนโลโก้ทั้งหมดให้เป็นรูปภาพของ ROHN ใน Navbar.jsx, ESlip.jsx และ StaffLogin.jsx

2. ข้อมูลจำลอง (Mock-up Data) ที่ถูกใช้งานอยู่

  • LiveLeaderboard.jsx: มีการจำลองอาร์เรย์ mockRunners และ mockSt ขึ้นมาแสดงผลแทนที่ หากในระบบยังไม่มีนักวิ่งคนใดเข้าเส้นชัย (hasAnyFinish === false)
  • OverallDashboard.jsx: ใช้ลอจิกเดียวกันในการแสดงผลข้อมูล mockRunners เพื่อให้แอดมินเห็นหน้าตา Dashboard ได้แม้การแข่งจะยังไม่เริ่ม

3. จุดที่ยังไม่สมบูรณ์ / การเชื่อมต่อ Backend ที่ขาดหาย (Missing Connections)

  • สีใน OverallDashboard: หน้า Overall Dashboard ยังไม่ได้ถูกเขียนโค้ดให้ดึงข้อมูลตาราง categories มาทำสีหัวตาราง (มีแค่ใน LiveLeaderboard ที่ทำไปแล้ว)
  • ระบบปริ้นท์ e-Slip แบบหลายใบ (Bulk Print): คำสั่งพิมพ์ตอนนี้เป็นการสั่ง window.print() แบบพื้นฐานสำหรับทีละบุคคล ยังไม่รองรับการ Gen PDF ผ่าน Backend รวดเดียวหลายๆ คน
  • ระบบ Realtime (WebSocket): การอัปเดตข้อมูลนักวิ่งในหน้า Dashboard/Leaderboard ตอนนี้ใช้วิธีกดปุ่ม Refresh ธรรมดา ยังไม่ได้เปิดใช้งาน Supabase Realtime เพื่อให้ขยับเองสดๆ แบบไม่ต้องรีเฟรชเว็บ
  • พาธของโลโก้ (Image Paths): ปัจจุบันเรียกใช้รูปโลโก้ด้วยพาธ /src/LOGO/... ตรงๆ ซึ่งเมื่อทำการ Build ขึ้นโปรดักชั่น (Vite build) อาจเกิดปัญหาหาไฟล์ไม่เจอ (404 Error) แนะนำให้ย้ายโฟลเดอร์ LOGO ไปไว้ใน public หรือเปลี่ยนไปใช้คำสั่ง import ของ JS แทนครับ
