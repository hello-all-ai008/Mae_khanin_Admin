1.4 ปรับโครงสร้างข้อมูลนักวิ่งแนวตั้ง, แสดงเพศ (Gender) และจัดวางจอ Monitor (Monitor.jsx)

แก้ไขและปรับแต่งโครงสร้างหน้าจอแสดงผลนักวิ่ง (Monitor.jsx) ให้อ่านง่าย ชัดเจนจากระยะไกล และใช้งานได้สมบูรณ์ในทุกขนาดหน้าจอ:

  • จัดเรียงข้อมูลนักวิ่งแบบแนวตั้ง (Vertical Stacked Hierarchy): ปรับเปลี่ยนพื้นที่ใต้ชื่อนักวิ่งจากแนวนอนเดิม มาเป็นแนวตั้ง (flex-direction: column) พร้อมขยายขนาดตัวอักษรให้อ่านง่ายระดับสายตาจากระยะไกล:
    • ป้ายรุ่นและระยะทาง: ขยายฟอนต์ใหญ่เป็น clamp(1.8rem, 3.2vw, 3.8rem) แสดงผลในรูปแบบ [ระยะ] : [ชื่อรุ่น] พร้อมใส่พื้นหลังสีประจำรุ่น
    • แสดงเพศ (Gender): เพิ่มการแสดงเพศภาษาอังกฤษมาตรฐาน (Male / Female โดยประมวลผลผ่าน isMale และ isFemale) ตัวหนาขนาด clamp(1.8rem, 3.2vw, 3.8rem)
    • กลุ่มอายุ (Age Group): ปรับขนาดฟอนต์เป็น clamp(1.8rem, 3.2vw, 3.8rem) ชัดเจนบนจอเวที
  • ป้องกันปุ่มตั้งค่าบังแผนที่ (Settings Button Clearance): เพิ่ม paddingTop: '5rem' ให้กับพื้นที่ฝั่งขวา (แผนที่และโลโก้) พร้อมจัดโครงสร้างแบบ Flex Column (alignSelf: 'center') เพื่อป้องกันไม่ให้ปุ่มลอย "ตั้งค่า / ปิดจอ" ที่มุมขวาบนลงมาบดบังหรือทับซ้อนกับภาพแผนที่เส้นทางวิ่ง
  • Re-Keying Active Container: เปลี่ยนการระบุคีย์อนิเมชันจาก key={castEvent?.timestamp} มาเป็น key={displayData.timestamp || 'initial'} เพื่อรับประกันว่าทุกครั้งที่มีการสแกนใหม่, การสลับรายชื่อนักวิ่ง, หรือการป้อน BIB ด้วยตนเอง (Manual BIB) หน้าจอจะเล่น CSS Entrance Animation และรีเซ็ตเวลานับถอยหลังใหม่อย่างแม่นยำ 100% ไม่ติดค้าง
  • ขยายขนาดโลโก้งานวิ่งและผู้สนับสนุน: ปรับสเกล Responsive Logo ให้ใหญ่ ชัดเจน และสมส่วนยิ่งขึ้นบนจอแสดงผลขนาดใหญ่:
    • โลโก้บ้านโป่ง (Logo Baan Pong) & แม่ขะนิง: ปรับเพิ่มเป็น clamp(55px, 6vw, 90px)
    • โลโก้ ROHN Full: ปรับเพิ่มเป็น clamp(65px, 7.5vw, 110px)
    • จัดระยะแบบ justifyContent: 'space-around' พร้อมเพิ่ม Padding และปรับความสูงบนจอขนาดเล็กเป็น height: 60px !important
  • Category Color Glow: หมายเลข BIB และข้อมูลนักวิ่งเรืองแสงตามสีประจำรุ่นการแข่งขัน (catColor) สอดคล้องกับฐานข้อมูล

3 การอ้างอิงแหล่งข้อมูลในระบบ (อิงตาม DatabaseFlow.jsx)

ตารางข้อมูลอ้างอิงหลักที่ใช้ในการทำงานของระบบ Trail Running Hub มีดังนี้:

ข้อมูล / ความต้องการ ตารางหลัก (Primary Table) คอลัมน์ที่ใช้งาน คำอธิบายและการนำไปใช้
ขอบเขตงานวิ่ง (Event Scope) events id, name, status ใช้เป็นตัวกรองข้อมูลหลัก (Scope) ของระบบทั้งหมด
ชื่อหมวดหมู่สะอาด runners / categories runners.cat_name, categories.name ชื่อประเภทการแข่งขันที่ไม่มีตัวเลขกิโล (เช่น Soft Rock)
ชื่อรุ่นเต็มพร้อมระยะ runners runners.cat ข้อความรวมสำหรับแสดงผลหน้าเว็บและ Leaderboard [ระยะ] KM : [ชื่อรุ่น]
ระยะทาง & หน่วย runners / categories distance (float), unit (varchar) ระยะทางตัวเลข (เช่น 5, 10) และหน่วย 'KM' สำหรับจัดเงื่อนไข Auto-Route
สีประจำรุ่น (Category Color) categories color รหัสสี Hex สำหรับการ์ดหน้า Monitor, แสง Glow และป้ายรุ่น
หมายเลข BIB runners bib รหัสประจำตัวนักวิ่ง ต้องไม่ซ้ำกันในงานเดียวกัน (UNIQUE ต่อ event_id)
เพศ runners gender เก็บเป็นภาษาอังกฤษตัวเต็ม: 'Male' หรือ 'Female'
กลุ่มอายุ runners age_group (สำรอง: age) รุ่นอายุการแข่งขัน เช่น 20-29, 30-39 สำหรับจัดอันดับรุ่น
จุดสแกนและเวลา Cutoff stations & checkpoint stations.type, checkpoint.cutoff_time กำหนดสถานะจุดสแกน (START, CP, FINISH) และเวลาตัดตัว Cutoff
ประวัติการสแกนเวลา scan_logs runner_id, station_id, scan_time, scanned_by บันทึกเวลาจริงที่สแกนผ่าน RPC ลง Database อย่างปลอดภัย
