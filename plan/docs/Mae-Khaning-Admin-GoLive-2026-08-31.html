5 เหตุการณ์ระหว่างทางที่ควรทราบ

สร้าง Vercel project ผิดตัวแล้วลบทิ้ง ตอน link project ครั้งแรก ระบบสร้าง project ใหม่ชื่อ rohn-mu ขึ้นมาโดยไม่ได้ตั้งใจ (เข้าใจผิดว่าชื่อ project = ชื่อโดเมน) ตรวจพบทันที ลบ project ที่สร้างผิดออก แล้ว link เข้ากับ rohn-admin ซึ่งเป็น project จริงที่ผูกโดเมน rohn-mu.vercel.app อยู่แล้ว ไม่มีผลกระทบต่อของจริง
ไฟล์ handoff ที่เคยดูเหมือนหาย ระหว่างตรวจ git status พบว่าไฟล์ handoff เก่า 2 ไฟล์ถูกทำเครื่องหมายว่าลบจาก working tree — ที่จริงกองย้ายไปไว้ที่ ai-whale/handoff/ (root ของ workspace) ตามธรรมเนียมใหม่แล้ว ไม่มีข้อมูลสูญหาย
